Ты работаешь с официальным API DTF. Прежде чем писать или изменять код для провайдера `src/lib/api/providers/dtf.ts`, тебе **НЕОБХОДИМО** изучить актуальную документацию API.

Документация (в формате YAML) находится в директории рядом с этим файлом: `references/`

Твои шаги при работе с DTF API:
1. Прочитай YAML файлы в папке `references/`, чтобы понять актуальную структуру запросов (URL, параметры) и ответов (JSON-схемы).
2. Убедись, что новые типы данных добавлены в `src/lib/api/types.ts`.
3. Только после этого реализуй методы в классе `DtfApiProvider`.
4. В случае любых сетевых ошибок, перехватывай их внутри провайдера и возвращай стандартизированную ошибку, чтобы UI не падал (согласно общим правилам AGENTS.md).
