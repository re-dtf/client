# Как участвовать

Спасибо, что хотите помочь. Здесь коротко, как устроена работа над проектом. Архитектура описана в [docs/architecture](docs/architecture/README.md), правила для агентов в [AGENTS.md](AGENTS.md) (людям они тоже полезны).

## Перед началом

1. Установите Node.js 26+, выполните `npm install`.
2. Скопируйте `.env.example` в `.env` (адрес прокси нужен только для входа по паролю).
3. `npm run dev` поднимает приложение, `npm test` запускает тесты, `npm run check` проверяет типы.

Крупное изменение (новая тема, новый элемент интерфейса, новая зависимость) сначала обсудите в issue: у темы `dtf2022` есть строгие правила, а размер бандла для нас важен.

## Принципы кода

- **Svelte 5, только руны.** `$state`, `$derived`, `$props`, `onclick={…}`, сниппеты. Без `$:`, `export let`, `on:click`, `<slot>` и сторов.
- **TypeScript без `any`**, кроме разбора чужих ответов API внутри провайдера.
- **Табы, комментарии на русском**, имена на английском. Комментарий объясняет «почему», а не повторяет код.
- **Не больше, чем нужно.** Не добавляйте абстракции и зависимости «на будущее». Нетривиальная логика получает один тест рядом с кодом.
- **Слои не смешиваем.** Данные только через фасад `api`, настройки и localStorage только через `persistedState`, переходы только через `$lib/navigation`, оформление темы только внутри папки темы. Подробности в [AGENTS.md](AGENTS.md).

## Перед отправкой изменений

- `npm test` проходит.
- `npm run check` не показывает новых ошибок. Сейчас в проекте есть около 50 старых, в основном в заглушках `classic` и `modern`.
- Изменение работает в браузере: откройте затронутый экран на ширине 1280 и 390 пикселей, проверьте консоль.
- Если вы сменили формат данных в localStorage, увеличьте `version` у соответствующего `persistedState`. Миграции до релиза не пишем.
- Если вы приняли решение, которое трудно восстановить по коду, добавьте короткую запись в [docs/decisions](docs/decisions/README.md).

## Коммиты

Одна логическая правка — один коммит. Заголовок на английском, в повелительном наклонении и без точки: `Add settings tab for theme`, `Fix feed reload on tab switch`. В теле, если нужно, коротко на русском или английском, зачем изменение.
