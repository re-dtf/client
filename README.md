# reDTF (Web Client)

SPA-клиент для социальной сети DTF.

## Быстрый старт

```bash
npm install
npm run dev -- --open
```

## Краткая справка по архитектуре

Этот проект спроектирован с упором на 3 вещи: прозрачность, масштабируемость и кастомизацию.

1. **SPA без SSR (Github Pages Ready):**
   Приложение использует `@sveltejs/adapter-static`. Выключен SSR (`src/routes/+layout.ts -> ssr = false`). Все сетевые запросы делает сам браузер пользователя — это гарантирует максимальную безопасность и прозрачность.

2. **Слой API (Facade Pattern):**
   - Все интерфейсы и типы лежат в `src/lib/api/types.ts`.
   - Самостоятельные провайдеры (DTF, Custom, и т.д.) лежат в `src/lib/api/providers/`.
   - Точка входа приложения: `src/lib/api/index.svelte.ts` (Фасад).
   - *Важно:* UI-компоненты вызывают только методы фасада (`api.getPosts()`). Фасад сам решает, из какого провайдера (или сразу из двух) отдать данные, основываясь на пользовательских настройках.

3. **Система Ленивых Тем (Lazy Themes):**
   - Темы — это не просто CSS, это целые наборы Svelte-компонентов с разной структурой.
   - Загрузкой занимается `src/lib/themes/ThemeLoader.svelte`. Он подтягивает компоненты асинхронно через динамический импорт (`await import(...)`).
   - *Важно:* Благодаря этому неиспользуемые темы не засоряют бандл. Браузер грузит JS только той темы, которая выбрана в данный момент.

4. **Svelte 5:**
   Приложение написано с использованием новых рун (`$state`, `$derived`, `$props`).
