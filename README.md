# reDTF

Неофициальный клиент для [DTF](https://dtf.ru): лента, посты, комментарии, профили и редактор. Работает целиком в браузере, без своего сервера, и умеет менять оформление, в том числе вернуть старый вид сайта.

> [!WARNING]
> **Проект в стадии прототипа.** Интерфейс и часть архитектуры ещё будут меняться. Формат данных в localStorage тоже: после обновления может понадобиться заново войти и выбрать настройки.

## Чем он отличается

- **Прозрачность.** Приложение статичное, запросы идут из вашего браузера прямо в API DTF. Никакого своего сервера, который видел бы ваши данные. Единственное исключение: вход по паролю требует CORS-прокси (код на 30 строк, можно развернуть у себя, см. [reDTF-proxy](https://github.com/re-dtf/proxy)).
- **Темы.** Тема — не просто цвета, а целый набор компонентов. Сейчас основная тема `dtf2022` воспроизводит DTF начала 2023 года. У каждой темы есть собственные настройки (например, вид оценок).
- **Источники данных.** Помимо DTF можно подключить сторонние источники по JSON-манифесту: например, архив удалённых комментариев. Каждый источник получает только те разрешения, которые вы одобрили.

## Быстрый старт

Нужен Node.js 26 или новее.

```bash
npm install
npm run dev -- --open
```

Для входа по паролю нужен адрес прокси: скопируйте `.env.example` в `.env` и укажите `VITE_AUTH_PROXY_URL` или впишите свой прокси в настройках приложения.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер |
| `npm test` | юнит-тесты |
| `npm run check` | проверка типов (`svelte-check`) |
| `npm run build` | статическая сборка в `build/` |
| `npm run preview` | посмотреть собранную версию |

## Публикация

- Ветка `dev` собирается и выкладывается на Cloudflare Pages (`.github/workflows`).
- Тег `v*` выкладывает стабильную версию на GitHub Pages.

Приложение — статические файлы, так что подойдёт любой статический хостинг. Если оно живёт не в корне домена, задайте `BASE_PATH`.

## Как устроен проект

Кратко: SvelteKit 3 и Svelte 5 в режиме SPA (`adapter-static`, `ssr = false`).

```
src/
  routes/            маршруты и корневой layout (оверлеи, тема)
  lib/
    api/             фасад api, провайдеры (DTF и подключаемые источники)
    themes/          реестр тем, ThemeLoader, сами темы
    storage/         всё, что хранится в localStorage
    components/      общие компоненты: блоки постов, комментарии, редактор, настройки
    navigation.ts    открытие и закрытие оверлеев
docs/                документация
```

Полная картина с диаграммой — в [docs/architecture](docs/architecture/README.md). Оглавление всей документации — [docs/README.md](docs/README.md).
