# 0008. Универсальный переход страниц на WAAPI без View Transitions API

Статус: принято
Дата: 2026-11-03

## Контекст

Нужен универсальный переход между страницами (лента-пост, пост-профиль, пост-пост и т.д.): уход старого экрана вглубь (Recede), фаза живого ожидания с размытием и индикатором загрузки при долгой сети (Hold), и плавное приближение нового экрана (Approach) с раскрытием рамки из карточки (Container Transform) или перелётом аватара.

View Transitions API (`document.startViewTransition`) является стандартным средством для анимирования переходов в SPA, но имеет архитектурные ограничения для данной задачи:
- колбэк `startViewTransition` блокирует отрисовку кадров браузером до своего разрешения;
- во время ожидания асинхронных сетевых данных снимки старого состояния статичны, активные анимации внутри снимков замирают (живое «дыхание» и появление спиннера темы невозможны);
- View Transitions не даёт гибкого контроля над непрерывным переходом размытия с уходящего экрана на входящий при долгой загрузке.

## Решение

- Реализовать оркестрацию переходов в ядре через Web Animations API (`src/lib/pageTransition.svelte.ts`) и управление состоянием слоёв оверлеев.
- Уходящий экран на время перехода фиксируется поверх области просмотра (`freeze`), изолируя геометрию и предотвращая нежелательные пересчеты раскладки на длинных лентах.
- Входящий экран монтируется в DOM в скрытом состоянии, подгружая необходимые ресурсы; готовность сигнализируется через существующий механизм `Reveal`.
- Все фазы движения (Recede, Wait, Breathe, Depart, Approach, Container) определяются декларативными данными активной темы (`ThemeMotion`).
- Для связанных переходов используется вычисление `clip-path` из прямоугольника исходной карточки или перелёт аватара через FLIP.

## Последствия

- Темы без поддержки универсального перехода (или с включённым системным «уменьшить движение») сохраняют прежнее мгновенное переключение без накладных расходов.
- Полный контроль над поведением при отмене навигации («Назад» во время ожидания возвращает старый экран без скачков).
- Нет зависимости от браузерных ограничений View Transitions API при медленных сетевых запросах.
