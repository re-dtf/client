# Мобильное приложение (Capacitor и OTA)

reDTF собирается не только как статическое веб-приложение (SPA/PWA), но и как нативное приложение для Android на базе **Capacitor 8**.

## Архитектура нативного слоя

Весь код нативной интеграции изолирован в модуле `src/lib/capacitor/`:

| Файл / директория | Назначение |
| --- | --- |
| `capacitor/index.ts` | определение платформы (`isNative()`), управление системным статус-баром и splash-экраном |
| `capacitor/updater.svelte.ts` | фоновая проверка, загрузка и применение OTA-обновлений бандла через Capgo Updater |
| `capacitor/updater.test.ts`, `index.test.ts` | юнит-тесты нативного слоя |
| `scripts/bundle-ota.js` | создание легковесного `bundle.zip` без внешних зависимостей (только Node.js `zlib/fs`) |
| `android/` | проект Android Studio (Gradle, Android SDK) |

## Особенности нативной платформы

1. **Отсутствие CORS**:
   - На нативных устройствах (`isNative() === true`) сетевые запросы авторизации отправляются напрямую в `api.dtf.ru`, минуя CORS-прокси.
   - Прокси в настройках приложения для нативных платформ по умолчанию отключаются.

2. **Бесшовные OTA-обновления (Over-the-Air)**:
   - Клиент интегрирован с плагином `@capgo/capacitor-updater`.
   - При запуске и возврате из фона `updater.svelte.ts` сверяет версию установленного веб-бандла с версией на сервере (`/api/version.json` или GitHub Releases).
   - При обнаружении нового выпуска загружается `bundle.zip`, распаковывается в изолированную директорию и применяется при следующем запуске без необходимости переустановки APK.

3. **Аппаратный виброотклик (Haptics)**:
   - Модуль `$lib/haptics` определяет наличие нативного Capacitor Haptics (`Haptics.impact({ style: ImpactStyle.Light })`) и переключается на нативный виброотклик вместо веб-вибрации `navigator.vibrate`.

4. **Системные Safe Area и статус-бар**:
   - Статус-бар подстраивается под активную палитру темы (`StatusBar.setStyle`, `StatusBar.setBackgroundColor`).
   - Поддерживается полноэкранный режим с учётом системных вырезов экрана.

## Команды для сборки

| Команда | Описание |
| --- | --- |
| `npm run cap:sync` | выполняет сборку `npm run build` и синхронизирует ассеты в `android/` |
| `npm run cap:open` | открывает проект `android/` в Android Studio |
| `npm run cap:run` | собирает и запускает приложение на подключённом Android-устройстве или эмуляторе |
| `npm run bundle:ota` | упаковывает директорию `build/` в архив `bundle.zip` для OTA-релиза |
| `npm run build:ota` | полный цикл: веб-сборка + упаковка `bundle.zip` |
