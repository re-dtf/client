## Как писать эти документы

- Простым языком, без терминов разработки. Если термин нужен («прокси», «токен»), объясните его в одном предложении.
- Каждый раздел отвечает на вопрос «как мне…» и сразу показывает шаги.
- Скриншоты хранить в `docs/user/images/` и подписывать. Показывать актуальную тему `dtf2022`.
- Не обещать то, чего в приложении ещё нет. Когда функция появляется, обновляйте раздел в том же изменении.
- Когда в проекте появится мастер первой настройки (`redtf:setup:*`), добавить его описание в «Начало работы».
