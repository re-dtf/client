# Источники данных

> Статус: черновик. Технические подробности для разработчиков: [architecture/data-sources](../architecture/data-sources/README.md).

Кроме DTF в reDTF можно подключить дополнительные источники: например, архив удалённых комментариев или другую систему реакций. Источник — это адрес файла-описания (манифеста), в котором сказано, откуда брать данные и что источнику нужно разрешить.

## Какие разрешения бывают

Для чтения данных разрешения не нужны: при подключении вы видите, откуда источник берёт данные. Разрешения запрашиваются только на действия, которые меняют то, что вы видите или делаете:

- **Дополнить комментарии** — показывать комментарии источника рядом с комментариями DTF.
- **Заменить комментарии** — подменить комментарии DTF комментариями источника.
- **Ставить реакции** — отправлять ваши реакции источнику.
- **Запись в «О себе»** — только для проверки владения аккаунтом (см. ниже).

## Вход в источник

Некоторые источники просят подтвердить, что вы — это вы. Поддерживаются:

- без входа;
- ручной ввод ключа;
- вход через OAuth;
- **проверка через «О себе»** (`re:connect`): приложение временно записывает код в описание вашего профиля на DTF, источник проверяет его наличие, после чего профиль возвращается к прежнему виду. TODO: описать, что делать, если проверка оборвалась.

## Безопасность

- Токен DTF никогда не отправляется источникам.
- Источник получает только те запросы, которые нужны для показа данных, и те права, которые вы ему выдали.
- Выключите или удалите источник, если не доверяете ему: его токен удаляется вместе с ним.
- Если источник не отвечает, остальные данные всё равно показываются.
